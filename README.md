# अपाङ्गता सूचना केन्द्र (Disability Information Center - DIC)

कोशी प्रदेश अन्तर्गतका १४ जिल्ला र १३७ वटै स्थानीय तहका लागि डिजिटल कानुन तथा नीतिगत भण्डार र वार्षिक प्रतिवेदन प्रणाली।

> **पहुँचयुक्त सूचना प्रणाली (WCAG 2.2 AA Standard)**  
> **प्राविधिक संरचना:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, SheetJS (XLSX), Lucide Icons, Supabase / PostgreSQL DDL

---

## 📌 प्रमुख विशेषताहरू (Key Features)

1. **स्थानीय तह वार्षिक प्रतिवेदन वेब फारम इन्जिन (Annual Reporting Form Engine):**
   - राष्ट्रिय ढाँचा `अपाङ्गता सहायता सहजकर्ता वार्षिक प्रतिवेदन ०८२.०८३.xlsx` अनुसार १३ वटा खण्ड र ४४ वटै मूल प्रश्नहरूको व्यवस्था।
   - **अनुसूची १.१ गृहभेट विवरण तालिका:** १० स्तम्भीय गतिशील (dynamic) प्रविष्टि।
   - **अनुसूची १.२ सहायक सामग्री वितरण तालिका:** १२ स्तम्भीय गतिशील प्रविष्टि।
   - **स्वचालित हिसाब (Auto Calculations):** लैङ्गिक जम्मा, Q9 सक्रिय अपाङ्गता संख्या `Q2 - (Q7 + Q8)`, र बिउपुँजी वित्तीय गणित।

2. **३ वटै पाना भएको Excel (.xlsx) निर्यात र प्रिन्ट/PDF:**
   - फारम र प्रोफाइलबाट सिधै मूल एक्सेल ढाँचामा `प्रश्न`, `अनुसूचि १.१ गृहभेट` र `अनुसूचि १.२ सहायक सामग्री` सहित ३-पाने स्प्रेडसिट डाउनलोड।
   - ब्राउजरबाट एक-क्लिक PDF / Print सुविधा।

3. **कोशी प्रदेशका १४ जिल्ला र १३७ स्थानीय तह सूची (Koshi Province Geography):**
   - ताप्लेजुङ देखि सुनसरी सम्मका सम्पूर्ण १ महानगरपालिका, २ उपमहानगरपालिका, ४६ नगरपालिका, र ८८ गाउँपालिकाको आधिकारिक सूची।

4. **स्थानीय तह वस्तुस्थिति प्रोफाइल (Palika Demographic Profile):**
   - प्रत्येक स्थानीय तहको वडा संख्या, सहजकर्ता सम्पर्क, १० प्रकारका अपाङ्गता अनुसार वर्गीकरण तालिका, परिचयपत्र रंग (क, ख, ग, घ) वितरण, र प्रतिवेदन दाखिला इतिहास।

5. **डिजिटल कानुन तथा नीतिगत भण्डार (Laws & Policy Repository):**
   - संघीय कानुन तथा सातै प्रदेशका ऐन, नियमावली, कार्यविधि, निर्देशिका, मार्गदर्शन, र परिपत्रहरू।
   - सिमुलेटेड PDF रिडर, फन्ट जुम, र डाउनलोड सुविधा।

6. **विषयगत तथ्याङ्क विश्लेषण तथा प्रतिवेदन (Reports & Analytics):**
   - ५ वटा विश्लेषणात्मक प्रतिवेदन (समग्र प्रगति, गृहभेट, सहायक सामग्री, जनसांख्यिकी र पालिकागत तुलना) र सबै चार्टसँगै पहुँचयोग्य डाटा तालिकाहरू।

7. **समाचार, परिपत्र तथा समीक्षक ड्यासबोर्ड (News & Admin Dashboard):**
   - आधिकारिक सूचनाहरू, परिपत्रहरू, र १३७ वटै पालिकाको प्रतिवेदन परीक्षण/स्वीकृति कार्यप्रवाह।

8. **पूर्ण पहुँचयुक्तता (WCAG 2.2 AA Accessibility):**
   - फन्ट साइज समायोजन (A+, Reset, A-), हाई-कन्ट्रास्ट मोड, नेपाली / अंग्रेजी भाषा परिवर्तन, र किबोर्ड Skip to content सुविधा।

## 🛠️ प्रविधि (Tech Stack)

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Vanilla CSS accessibility tokens
- **Data Export:** SheetJS (`xlsx`)
- **Icons:** `lucide-react`
- **Database Architecture:** PostgreSQL DDL with Row Level Security (RLS) located in `supabase/seed.sql`

## 🚀 सञ्चालन विधि (Getting Started)

### १. डिपेन्डेन्सी इन्स्टल गर्नुहोस्:
```bash
npm install
```

### २. डेभलपमेन्ट सर्भर सुरु गर्नुहोस्:
```bash
npm run dev -- -p 3001
```
ब्राउजरमा [http://localhost:3001](http://localhost:3001) खोलेर हेर्नुहोस्।

### ३. प्रोडक्सन बिल्ड:
```bash
npm run build
npm run start -- -p 3001
```
